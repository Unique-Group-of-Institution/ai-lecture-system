# Definition of Done

A task may move to REVIEW only when:

- acceptance criteria are addressed;
- relevant automated checks pass;
- no secrets or private media were added to Git;
- Windows instructions are updated when setup changes;
- failure behavior is safe and recoverable;
- `docs/STATUS.md` and `handoffs/LATEST.md` reflect the result;
- the task history includes verification evidence.

A task may move from REVIEW to DONE only when:

- a different reviewer or human verifies the acceptance criteria;
- reported defects are resolved or explicitly accepted;
- any approval-gated action remains unexecuted until separately authorized.
